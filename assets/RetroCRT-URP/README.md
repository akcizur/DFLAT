# Retro CRT / PS1 — Unity URP package

A lightweight URP package with a fullscreen CRT post-process, a PS1-inspired lit shader, four ready-to-use profiles, and an optional frame-rate cap.

**Quick install:** copy this folder into `Assets/RetroCRT-URP`, add `Retro CRT Renderer Feature` to the active URP Renderer asset, assign `Materials/RetroCRT_PostProcess.mat`, and select one of the `Presets/RetroCRT_*.asset` profiles.

See [Czech setup and troubleshooting guide](Documentation/README.cs-CZ.md) for the full setup, supported Unity paths, material instructions, and known limitations.
